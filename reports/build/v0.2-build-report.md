## Payload engineering (tools/build/gen_payload.py)

- CrAU v2, manifest minor_version=8, block 4096, unsigned (no signature ops)
- 11 partitions as uncompressed REPLACE ops (64 MiB chunks), linear extents
- `dynamic_partition_metadata`: group `google_dynamic_partitions` (max 8,528,650,240 B), snapshot disabled
- **data_offset is global across partitions** — first run failed self-test on
  `dtbo` because per-partition reset made every partition claim offset 0
  (boot passed by luck; wagon-2 read wagon-1's bytes). Fixed with a running counter.
- Per-op `data_sha256_hash` set at manifest build time (two-pass)
- properties: FILE_HASH/FILE_SIZE/METADATA_HASH/METADATA_SIZE — definitions
  **verified against the real LineageOS signed OTA** (METADATA_SIZE = 24 +
  manifest_size; METADATA_HASH = sha256(header+manifest))

## Zip structure (tools/build/make_sideload_zip.py)

Hand-rolled STORED zip (zipfile's streaming path hits a size guard at 3 GB and
auto-extras broke offsets). Single entry each, offsets exact:

- `META-INF/com/android/metadata` @0 — `pre-device=raven`, `ota-type=AB`,
  `post-timestamp=now` (≥ installed builds → no anti-rollback rejection),
  `ota-property-files` = exact local-header offsets (verified PK\x03\x04)
- `payload.bin` @512 — 3,037,408,886 B
- `payload_properties.txt` @3,037,409,439

`unzip -t`: **no errors**.

## Owner instructions

1. **Back up** (factory reset is part of this flow — FBE fix)
2. Boot LineageOS recovery → "Apply update from ADB"
3. `adb sideload project-color-raven-v0.2-raven-sideload.zip`
4. After install completes: recovery → **Factory reset / Wipe data** (FBE fix — required)
5. Reboot → first boot may take 2–10 min
6. Report: (a) boots clean (b) boots but broken (c) bootloop

## Risks / fallbacks

- If recovery rejects the **unsigned** package (signature verification), the
  audited fastboot package (v0.1) remains the fallback
- The previous ROM stays on the inactive slot → boot-failure auto-revert available
- GCam addon lives in the v0.1 package (`extras/gcam/splits/`) — install after first boot
